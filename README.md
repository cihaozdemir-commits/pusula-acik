# pusula-acik

Pusula laboratuvarının herkese açık, A sınıfı türetilmiş veri kopyası. Yatırım tavsiyesi değildir.

Kaynak: Türkiye Cumhuriyet Merkez Bankası, Elektronik Veri Dağıtım Sistemi (EVDS), https://evds3.tcmb.gov.tr — EVDS kullanım koşulları (docId=18) uyarınca kaynak gösterilerek yayımlanmıştır. Veriler TCMB'ye aittir; bu depo yalnız teknik kopyadır.

İçerik: `veri/resmi/evds/*.csv` (tarih, değer, kaynak_sha12), `LISANS.json`, `MANIFEST.json` (sha256 + zaman damgası).
Ham yanıtlar, BIST arşivi, KAP/TEFAS verileri ve hiçbir anahtar bu depoda yoktur.
